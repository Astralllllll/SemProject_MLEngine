# SemProject_MLEngine — WakiliMatch AI

ICS 3202: Artificial Intelligence — Semester Project.

WakiliMatch AI is the ML engine for a Kenyan legal matching platform. It uses Sentence-Transformer (MiniLM) semantic retrieval over the Kenya Law corpus to match a user's legal problem to relevant case law, legislation and advocates.
